Что нужно помнить про историю

пробел в начале
команда, набранная с ведущим пробелом, в историю не попадёт. Так вводят строки с паролями и токенами
где лежит
~/.local/state/zsh/history, а не в репозитории: иначе токены из командной строки уехали бы в git
общая
все вкладки пишут в один файл и сразу видят команды друг друга
секреты
внутренние хосты, строки подключения и токены — в ~/.config/zsh/local.zsh, он вне git

Секреты

Пароли БД, токены, ключи и kubeconfig лежат в отдельном keychain dev, а не в Apple Passwords: у Passwords нет API. Команда sec прячет длинные вызовы security.

Положить

sec add имя
спросит значение скрытым вводом, на экране ничего не появится
-a · -n
аккаунт или логин · заметка: хост, порт, для чего
-f файл
сохранить файл целиком: ключ, kubeconfig, сертификат
-u
заменить существующую запись
из пайпа
printf '%s' токен | sec add kafka/token

Имена через слэш группируются: ssh/id_work, k8s/prod. Группы видны в sec ls и в автодополнении по Tab.

Достать

sec get имя
в stdout, чтобы подставить: $(sec get pg-staging)
sec cp имя · sc
в буфер обмена, очистится через 30 секунд
sec out имя путь
восстановить файл на диск с правами 600
sec ls
список записей без самих секретов, можно с префиксом
sec show имя
метаданные: аккаунт, заметка, когда создана
sec rm имя
удалить, -y без подтверждения

без аргументов — список с метаданными справа

Установщик

После переустановки

шрифт
iTerm2 → Profiles → Text → Font → MesloLGS Nerd Font Mono, иначе промпт рисует квадраты
Option
iTerm2 → Profiles → Keys → Left Option key → Esc+
первый nvim
плагины и языковые серверы ставятся сами, около минуты

Где что лежит

Всё в домашнем каталоге — симлинки в репозиторий. Правите файл в репозитории, изменения видны сразу.

Конфиги под контролем git

~/.zshenv
переменные окружения, PATH, XDG-каталоги. Читается всеми шеллами, включая запуск из Dock
~/.config/zsh/.zprofile
ставит Homebrew в начало PATH, иначе системный git перекрывает свежий
~/.config/zsh/.zshrc
загрузчик: Oh-My-Zsh, тема, модули
~/.config/zsh/conf.d/
00 опции · 10 клавиши · 20 инструменты · 30 алиасы
~/.config/git/config
настройки и алиасы git
~/.config/nvim/init.lua
весь конфиг редактора одним файлом
~/.config/lazygit/config.yml
lazygit, со шпаргалкой в комментариях
~/.config/tig/config
tig: колонки и свои клавиши
~/bin/sec
сама команда для секретов
~/.config/zsh/conf.d/40-sec.zsh
автодополнение sec и алиас sc

Вне репозитория

~/.config/git/identity
имя и почта для коммитовне в git
~/.config/zsh/local.zsh
секреты и настройки этой машиныне в git
~/.local/state/zsh/history
история команд
~/Library/Keychains/dev.keychain-db
сами секретыне в git
~/.dotfiles-backup/
то, что установщик убрал с дороги
Шпаргалка собрана по конфигам репозитория dotfiles. Цвета — Catppuccin Latte и Mocha, те же, что в nvim и bat. Нажмите / для фильтра. Один файл, без интернета: cheat в терминале.
